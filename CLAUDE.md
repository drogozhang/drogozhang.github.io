# Claude Code Rules for This Repository

This is Kai Zhang's personal academic website built with Hexo.

## Deployment

Deploy the site (push to gh-pages):
```bash
rm -rf .deploy_git/ && hexo clean && hexo d -g
```

Always remove `.deploy_git/` first when uploading new files.

## File Locations

- **CV**: `themes/cactus/source/files/cv_open.pdf` (source file)
- **Publications**: `source/_data/publications.json`
- **Selected Publications**: `source/_data/selectedPublications.json`
- **News**: `source/_data/news.json`
- **Bio/Intro**: `themes/cactus/layout/index.ejs`
- **Footer**: `themes/cactus/layout/_partial/footer.ejs`

## What NOT to Commit

- `public/*` - generated files, regenerated by `hexo g`
- `db.json` - hexo cache file
- `.deploy_git/` - deployment folder

## Committing vs Deploying

These are separate operations:
- **Deploy** (`hexo d -g`): Pushes generated site to `gh-pages` branch, makes changes live
- **Commit**: Saves source files to `new-look` branch for backup/version history

You can deploy without committing. Commit occasionally to checkpoint source files.

## Workflow

1. Make changes to source files
2. Deploy: `rm -rf .deploy_git/ && hexo clean && hexo d -g`
3. (Optional) Commit source changes: `git add <files> && git commit`
4. (Optional) Push commits: `git push origin new-look`

## Local Preview

```bash
hexo g && hexo s
```

Then open http://localhost:4000


## Quick Start

### Create a new post

``` bash
$ hexo new "My New Post"
```

### Run server

``` bash
$ npm install
$ hexo g
$ hexo s
```

### Deploy to remote sites

``` bash
$ hexo clean && hexo d -g
```

### Important modifies:

